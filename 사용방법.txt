퍼스널컬러 진단 앱 사용방법
==========================

■ 어떤 앱인가요
- 카메라로 고객의 피부·눈동자·머리카락 색을 측정해 봄·여름·가을·겨울 8타입
  (봄 웜 라이트/브라이트, 여름 쿨 라이트/뮤트, 가을 웜 뮤트/딥, 겨울 쿨 브라이트/딥)
  중 어울리는 타입을 "추정"합니다.
- 화면 속 얼굴 아래에 색 천(드레이프)을 띄워 고객이 직접 비교·선택하고,
  그 선택을 자동 분석과 합쳐 최종 결과를 보여줍니다.
- 얼굴 사진은 저장하거나 전송하지 않습니다. 모든 분석은 기기 안에서만 이루어지고,
  인터넷 연결 없이도 동작합니다(처음 한 번 접속해 두면 오프라인 사용 가능).

■ 준비
- 카메라는 HTTPS 주소 또는 localhost 에서만 켜집니다. (파일을 더블클릭해서 열면 카메라가 안 켜져요)
  → 호스팅 방법은 "호스팅안내.txt" 참고
- 휴대폰/태블릿: 사파리(아이폰·아이패드) 또는 크롬(안드로이드)에서 주소를 연 뒤
  "홈 화면에 추가"(사파리: 공유 버튼 → 홈 화면에 추가, 크롬: ⋮ → 앱 설치)하면 앱처럼 쓸 수 있어요.
- 노트북: 크롬/엣지에서 주소를 열고 주소창 오른쪽 "설치" 아이콘을 누르면 됩니다.
- 흰 A4 용지 한 장을 준비해 두면 색 보정이 더 정확해져요.

■ 진행 순서 (직원용)
1. [진단 시작] → 고객에게 촬영 안내를 보여주고 촬영 동의 체크 → [동의하고 시작하기]
   → 진단권 QR 확인 → 카메라 (카메라를 쓸 수 없으면 [사진 파일로 진단]으로 정면 사진을 골라도 됩니다)
2. 조명 확인·흰 종이 보정
   - 창가 자연광, 얼굴 정면으로 빛이 오게. 노란 조명·직사광선은 피하기
   - 흰 종이를 얼굴 옆 같은 빛 아래에서 화면 사각형 안에 가득 차게 비추고 [흰 종이로 보정하기]
   - 화면 왼쪽 위 표시(밝기/색 치우침)가 초록색이면 좋아요. 보정은 건너뛸 수도 있어요.
3. 얼굴 촬영: 얼굴을 타원 안에 맞추고 [촬영하고 분석]. 촬영 직후 카메라는 바로 꺼집니다.
   - 안경 벗기, 앞머리 넘기기, 컬러 렌즈·진한 메이크업은 피하기
   - 오른쪽 위 ⇄ 버튼으로 앞/뒤 카메라 전환
4. 자동 분석 결과: 1·2순위 후보와 신뢰도(높음/보통/낮음), 언더톤·명도·채도 막대를 확인
5. [드레이핑으로 확인하기]
   - 비교 진단(5단계): 웜 vs 쿨 → 골드 vs 실버 → 아이보리 vs 퓨어 화이트 → 라이트 vs 딥 → 브라이트 vs 뮤트
     고객에게 "어느 쪽이 얼굴이 더 맑고 화사해 보이세요?"라고 묻고 고른 쪽 버튼을 누르세요.
     (좌우 위치는 단계마다 바뀝니다. 애매하면 [비슷해요])
   - 팔레트 둘러보기: 왼쪽/오른쪽 시즌을 골라 12가지 색을 ◀ ▶ 버튼이나 화면 좌우 밀기로 넘겨 보며
     나란히 비교하고, 고객이 더 좋다고 한 쪽을 누르면 결과에 반영됩니다.
6. [최종 결과 보기]: 타입 이름, 설명, 베스트 컬러 12색, 피할 컬러, 메이크업·헤어·액세서리 팁
   - [결과 이미지 저장 (PNG)]: 색과 글자만 들어간 카드 이미지(얼굴 사진 없음)
     휴대폰에서는 공유 창이 열려 사진첩 저장·카톡 전송이 가능해요.
7. [다음 고객 (초기화)]: 측정값·선택·결과·카메라를 모두 지우고 처음으로 돌아갑니다.
   진행 중에는 상단 [처음으로] 버튼으로도 초기화할 수 있어요(확인창이 뜹니다).

■ 결과에 대해 고객에게 안내할 점
- 카메라와 조명에 따라 달라질 수 있는 "추정 결과"이며 전문가 대면 진단을 대신하지 않습니다.
- 신뢰도가 "낮음"이면 조명을 바꾸거나 흰 종이 보정 후 다시 촬영하고, 드레이핑 비교를 꼭 함께 해 주세요.
- 염색 모발, 컬러 렌즈, 메이크업, 태닝은 결과에 영향을 줍니다.

■ 개인정보
- 얼굴 영상·사진은 저장·전송하지 않고, 분석이 끝나면 메모리에서 지웁니다.
- 기기에 남는 것은 앱 파일(오프라인용 캐시)뿐이며 고객 정보나 결과는 저장되지 않습니다.
- 통계·광고·외부 서버 요청이 전혀 없습니다.

[결과 화면 추천 (v1.2)]
- 결과 화면의 탭(컬러 / 립 / 안경 / 눈썹)으로 시즌별 립 컬러, 안경테 컬러, 얼굴형별 안경테 모양과 눈썹 모양을 볼 수 있어요.
- 얼굴형은 얼굴 자동 인식 결과로 추정해요(계란형·둥근형·긴형·각진형·하트형·마름모형). 사진 각도·머리카락에 따라 달라질 수 있으니 직원이 보고 '얼굴형' 선택 상자에서 바꿔 주세요.
- 얼굴 자동 인식이 없는 경우(드레이핑만 하기 등)에는 얼굴형을 직접 골라야 안경 모양·눈썹 추천이 나와요.
- 결과 이미지(PNG)에도 립·안경·눈썹 추천이 함께 저장돼요. 모든 추천은 일반적인 스타일링 가이드에 따른 '제안'이에요.

[진단권 QR · 관리자 모드 (v1.4)]

■ 고객 진단 시작 (진단권 QR)
- [진단 시작] 또는 [드레이핑만 하기] → 먼저 '촬영 전 안내(동의)' 화면이 나오고, 카메라는 아직 꺼져 있어요.
- 고객이 안내를 읽고 [촬영에 동의] 칸을 체크하면
  '진단권 확인' 화면이 열리고 그때 카메라가 켜집니다.
  · QR 화면은 뒤 카메라를 먼저 써요. 고정된 태블릿에서 고객이 화면 쪽으로 카드를 보여 주는 경우
    오른쪽 위 ⇄ 버튼으로 앞 카메라로 바꾸면, 이 기기에서 그 선택을 기억해요.
  · 화면에 "카메라는 QR 확인에만 쓰고 저장하지 않아요" 안내가 표시돼요.
- 카드의 QR을 네모 안에 보여 주면 자동으로 확인되고 바로 보정(또는 드레이핑) 화면으로 넘어가요.
- 진단권은 1회용입니다. 진단이 '시작되는 순간' 사용 처리되며, 같은 카드를 다시 보여 주면
  "이미 사용된 QR 코드예요."라고 안내하고 거부합니다.
- 카메라가 QR을 못 읽거나 카메라 권한이 없으면 카드 아래쪽 코드(XXXX-XXXX-XXXX-XXXX-XXXX-XXXX)를
  입력칸에 넣고 [코드로 확인]. 대소문자·하이픈은 상관없어요.
- 위조·임의 QR, 취소된 코드, 유효기간이 지난 코드는 각각 안내 문구와 함께 거부됩니다.

■ 실수로 [처음으로]를 눌렀을 때 (이어하기)
- 첫 화면에 [↻ 진행 중인 진단 이어하기] 버튼이 생겨요. 이 버튼으로만 QR 없이 이어서 할 수 있어요.
- 이어하기는 10분 동안만 가능하고, 진단을 끝내거나 자동 초기화되면 사라져요.
- [진단 시작]을 누르면 새 진단으로 보고 다시 진단권 QR을 요구해요(같은 카드를 다시 보여 주면 이어하기).

■ 자동 초기화 (고객이 자리를 떠났을 때)
- 진단 중 2분 30초 동안 아무 조작이 없으면 "계속하시겠어요?" 창이 뜨고 20초를 셉니다.
- [계속하기]를 누르면 그대로 이어지고, 응답이 없으면 카메라를 끄고 결과를 지운 뒤 첫 화면으로 돌아가요.
  이때 이어하기도 지워져서 다음 사람이 QR 없이 이어서 쓸 수 없어요.

■ 결과를 고객 휴대폰으로 보내기 (서버 없음)
- 결과 화면 [📱 휴대폰으로 받기] → QR이 뜨면 고객이 휴대폰 카메라로 찍어 결과를 열어요.
- QR에는 이 사이트 주소 + 결과 코드(타입·2순위·신뢰도·방법·날짜·얼굴형)만 들어 있어요.
  얼굴 사진·측정값·이름은 없고, 주소의 # 뒤 내용은 서버로 전송되지 않아요.
- 고객 휴대폰에서는 읽기 전용 결과 화면(컬러/립/안경/눈썹 탭, 결과 이미지 저장)만 보여요.
  고객 휴대폰에 인터넷 연결이 필요해요.

■ 관리자 모드 들어가기
- 첫 화면 오른쪽 위의 작은 [관리자] 글자를 누르거나, 왼쪽 위 로고를 1초 정도 길게 누르세요.
- 초기 비밀번호: 담당자에게 따로 전달된 4자리 숫자 (이 안내문은 사이트에 공개되므로 번호를 적지 않았어요)
  → 처음 사용할 때 꼭 [설정] 탭에서 다른 비밀번호로 바꿔 주세요.
- 비밀번호를 5번 틀리면 1분 동안 잠깁니다.
- 3분 동안 아무 조작이 없으면 자동으로 로그아웃됩니다. 사용 후에는 [로그아웃]을 눌러 주세요.
  (인쇄 창이 떠 있는 동안은 로그아웃되지 않고, A4 인쇄 미리보기 화면에서는 15분까지 기다려요.)
- 상단에 "기기 시계가 뒤로 바뀌었어요" 경고가 보이면 기기의 날짜·시간 설정을 확인한 뒤 [확인함]을 누르세요.
  (시계를 뒤로 돌려도 만료된 진단권은 계속 거부돼요. 기기 날짜가 실제보다 이틀 이상 늦으면
   오늘 발급한 카드가 "발급일이 이 기기 날짜보다 뒤예요"로 거부되니 날짜를 맞춰 주세요.)
- 예전에 기기 시계가 미래로 잘못 맞춰졌다가 바로잡힌 경우, 정상 진단권도 "만료"로 거부될 수 있어요.
  이때 관리자 화면 위쪽 경고의 [지금 시각으로 기준 재설정]을 누르세요. 기기 날짜·시간이 맞는지 먼저 확인하고 누르세요.
  누른 기록(시각·이전 기준)은 설정 탭에 남아요.

■ [발급] 탭
1. 수량(1~50장), 유효기간(없음/30일/90일/180일/1년/날짜 지정), 묶음 메모(선택, 예: "10월 이벤트")를 정하고 [발급하기]
2. 카드 미리보기에서 ◀ ▶로 확인 (90×50mm 명함 크기, 일련번호·발급일·유효기간·QR 포함)
3. [A4 인쇄]: A4 한 장에 10장씩 배치된 인쇄 화면이 열려요(만드는 동안 진행 막대 표시).
   - [인쇄하기] → 용지 A4, 배율 "100%(실제 크기)", 여백 "없음". (페이지에 맞춤으로 인쇄하면 카드 크기가 달라져요)
   - 아이패드·안드로이드 인쇄 창은 여백·배율을 바꿀 수 있어서, 정확한 크기가 필요하면
     [PDF]로 저장한 뒤 PC에서 100%로 인쇄하는 것을 권장해요.
   - 카드 모서리 바깥의 재단선(크롭 마크)에 맞춰 자르세요.
4. [카드 PNG]: 지금 보이는 카드 1장을 고해상도(300dpi) 이미지로 저장 / [PDF 저장]: 이번에 발급한 카드 전체

■ [목록] 탭
- 묶음(메모·발급일·장수)과 상태(미사용/사용됨/취소됨/만료)로 골라 볼 수 있어요. 휴대폰에서는 날짜가 코드 아래에 보여요.
- 분실·도난 카드는 [취소]를 누르면 이 기기에서 더 이상 쓸 수 없어요.
- [이 목록의 미사용 코드 인쇄]: 지금 골라 본 목록 중 쓰지 않은 카드만 다시 인쇄해요.

■ [통계] 탭
- 오늘·최근 7일·최근 30일 이용 수, 최근 7일 막대그래프, 진단권 현황(미사용·사용·취소·만료·7일 안에 만료),
  시작 방법(QR·코드 입력·관리자 허가·다른 기기에서 가져온 기록), 묶음별 사용 수를 보여 줘요.
- 이 기기의 기록만 세요(다른 기기에서 가져온 사용 기록은 이용 수에서 빼요).

■ [설정] 탭
- 운영 정보: 운영 주체(기본 "H.O.W")와 문의처(전화번호 등)를 입력하면 고객 동의 화면에 표시돼요.
- 데이터 백업:
  · [백업 파일 저장 (JSON)]: 발급 목록·사용 기록·취소 기록·운영 정보·(바꾼) 비밀번호 해시를 파일로 저장.
    주기적으로(예: 매주) 저장해서 안전한 곳에 보관하세요. 기기 고장·교체·브라우저 데이터 삭제 때 필요해요.
  · [백업·기록 파일 불러오기]: 지금 기록에 합쳐요(지우지 않음). 비밀번호도 바꿀지 따로 물어봐요.
    파일 내용이 바뀌었으면 불러오지 않아요(서명 확인).
  · [발급 목록 엑셀(CSV)]: 일련번호·코드·발급일·만료일·묶음 메모·상태·사용 시각·사용 방법·취소 시각.
- 다른 기기와 사용 기록 맞추기 (태블릿 2대 이상일 때):
  · 파일: 기기 A [사용 기록 파일 저장] → 파일을 기기 B로 옮겨 [백업·기록 파일 불러오기]
  · QR: 기기 A [사용 기록 QR 보기] → 기기 B [QR로 가져오기 (카메라)]로 비추기 (24개씩 여러 쪽이면 ◀ ▶로 넘기며 차례로. QR을 화면 가득 크게 비춰 주세요)
  · 실시간 공유가 아니라 "옮긴 시점까지"만 맞춰져요. 하루 한 번(마감 때 등) 맞추는 것을 권장해요.
- 기기 설정: 화면 꺼짐 방지(기본 켜짐), 저장소 보호 요청, (지원 브라우저) 홈 화면에 앱 설치
- 비밀번호 변경

■ QR 없이 1회 허가 (아래 버튼)
- 카드를 깜빡한 고객 등을 위해 진단 1회를 허가해요. 누르면 관리자 모드가 닫히고,
  다음 진단 1번만 QR 없이 시작되며 이후에는 다시 QR이 필요해요.
- 여러 번 눌러도 쌓이지 않고 1회만 대기해요(다시 누르면 1시간 연장). 1시간 안에 쓰지 않으면 자동으로 사라져요.
- 고객 화면에는 횟수가 표시되지 않고 [관리자] 글자 옆에 작은 점만 보여요(직원 확인용).
- 대기 중인 허가는 관리자 화면 위쪽의 [허가 취소]로 취소할 수 있어요.

■ 매장 기기(키오스크)로 쓰기
- 오른쪽 위 ⛶ 버튼: 전체 화면(주소창 숨김). 다시 누르면 해제.
- 화면 꺼짐 방지가 켜져 있으면 앱이 열려 있는 동안 화면이 꺼지지 않아요(지원 브라우저).
  · 아이패드(특히 iOS 18.4 이전 홈 화면 앱)는 이 기능이 안 될 수 있어요. 설정 → 디스플레이 및 밝기 → 자동 잠금 → "안 함"으로 바꿔 두세요.
  · 안드로이드 태블릿도 화면이 꺼지면: 설정 → 디스플레이 → 화면 자동 꺼짐 시간을 길게 해 주세요.
- 고객 휴대폰에서 연 결과 보기 화면은 앱 파일(분석 엔진)을 받지 않고 화면 꺼짐 방지도 쓰지 않아요(데이터 절약).
- 기기를 다크 모드로 써도 앱은 항상 밝은 화면으로 보여요(색 비교가 바뀌지 않게).
- 고객이 다른 앱으로 나가지 못하게 하려면 기기 기능을 쓰세요.
  · 안드로이드: 설정 → 보안 → "앱 고정(화면 고정)" 켜기 → 최근 앱 화면에서 이 앱 아이콘 → 고정
  · 아이패드: 설정 → 손쉬운 사용 → "사용법 도우미(Guided Access)" 켜기 → 앱에서 측면(홈) 버튼 3번
- 꼭 "홈 화면에 추가(앱 설치)"해서 쓰세요. 아이패드 사파리는 홈 화면에 추가하지 않으면
  오래 쓰지 않을 때 기록(발급 목록·사용 기록)을 지울 수 있어요.

■ 새 버전 안내
- 새 버전이 올라오면 화면 아래에 "새 버전이 있어요 [새로고침]"이 떠요. 진단 중이면 끝난 뒤 눌러 주세요.
  (진단 중에 눌러도 첫 화면의 [이어하기]로 계속할 수 있어요.)

■ 개인정보 안내 (법률 검토 권장)
- 동의 화면에는 이용 목적, 처리 방식(기기 안 실시간 처리·저장 및 전송 안 함), 동의 거부 권리와 불이익,
  운영 주체·문의처가 표시돼요.
- 이 문구는 일반적인 안내 예시예요. 실제 매장 운영 전에 회사 개인정보 담당자·법무팀의 검토를 받아 주세요.
  (얼굴 영상 처리, 미성년 고객 응대 방식, 게시 위치 등)

■ 꼭 알아 두실 한계 (정직한 안내)
- 1회 사용 확인은 "이 기기 안에서만" 이루어져요. 서버가 없어 사용 기록이 이 기기의 브라우저 저장소에만 남아요.
  · 다른 기기(태블릿 2대 등)에서는 사용 기록을 옮기기 전까지 같은 카드를 한 번 더 쓸 수 있어요.
    실시간으로 막으려면 사용 기록을 모으는 서버(백엔드)가 필요해요.
  · 브라우저 데이터(사이트 데이터·캐시)를 지우면 사용 기록·발급 목록·변경한 비밀번호가 초기화돼요 → 백업 파일로 복원하세요.
  · 코드 취소도 취소한 기기(와 기록을 옮긴 기기)에서만 적용돼요.
- 카드·백업 파일의 서명(위조 방지)과 비밀번호 해시는 앱 코드에 들어 있어요. 비밀번호는 평문이 아닌
  솔트 해시(PBKDF2)로만 저장하지만, 이 앱은 누구나 받을 수 있는 공개 정적 웹사이트라서
  마음먹은 사람이 코드를 분석하면 진단권을 만들거나 4자리 비밀번호를 알아낼 수 있어요.
  "일반 고객이 임의로 쓰지 못하게 하는" 정도의 억제용 보안으로 생각해 주세요.
- 기기 시계는 앱이 확인할 수 있는 범위(마지막으로 본 시각보다 이른지)만 감지해요. 정확한 시각은 기기 설정에 따라요.
