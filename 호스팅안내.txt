호스팅(배포) 안내
================

카메라(getUserMedia)는 보안 연결에서만 동작합니다.
  - 가능: https://… 주소, 또는 같은 PC의 http://localhost
  - 불가: 파일 더블클릭(file://), http://192.168.x.x 같은 일반 http 주소
이 폴더(personal-color) 전체를 그대로 올리면 됩니다. 서버 프로그램이나 빌드 과정은 필요 없어요.
(폴더 용량 약 35MB — 대부분 얼굴 인식 모델/엔진 파일입니다)

※ 아직 어디에도 배포하지 않았습니다. 아래 방법 중 하나를 골라 직접 올리시거나 요청해 주세요.

1) Netlify Drop (가장 간단, 무료 계정)
   1. https://app.netlify.com/drop 접속 후 로그인
   2. personal-color 폴더를 브라우저 창에 끌어다 놓기
   3. 발급된 https://○○○.netlify.app 주소를 태블릿/폰에서 열기
   - 주소가 공개되므로, 원하면 Netlify의 비밀번호 보호(유료) 또는 어려운 주소 이름을 사용하세요.

2) GitHub Pages (무료)
   1. GitHub에 새 저장소를 만들고 personal-color 폴더 안의 파일들을 올리기
      (100MB 넘는 파일은 없음. 가장 큰 파일은 약 12MB)
   2. 저장소 Settings → Pages → Branch: main / (root) → Save
   3. 몇 분 뒤 https://아이디.github.io/저장소이름/ 으로 접속
   - 공개 저장소면 누구나 주소로 접근할 수 있어요(얼굴 데이터는 원래 서버로 가지 않습니다).

3) 회사 내부 웹서버 / 사내망
   - HTTPS가 설정된 아무 웹서버(IIS, Nginx 등)에 폴더를 복사하면 됩니다.
   - .wasm 파일은 application/wasm, .mjs 는 text/javascript 형식으로 전송되도록 설정하세요.

4) 노트북 한 대에서만 쓸 때 (localhost)
   - 파이썬이 있으면 폴더 안에서:  python -m http.server 8000
   - 브라우저에서 http://localhost:8000 접속 (같은 PC에서만 카메라 사용 가능)

업데이트 방법
- 파일을 바꾼 뒤 sw.js 맨 위의 VERSION 값(예: pc-v1.0.0 → pc-v1.0.1)을 올려서 다시 업로드하면
  다음 접속 때 새 버전으로 교체됩니다.

참고
- 처음 접속할 때 앱 파일이 기기에 저장되어, 이후에는 인터넷 없이도 열립니다.
- 얼굴 인식 엔진(MediaPipe, Apache-2.0)은 vendor/ 폴더에 포함되어 있으며,
  원래 구글 서버로 사용 통계를 보내는 코드가 있어 이 앱에서는 꺼 두었습니다(외부 요청 0건 테스트로 확인).
